    Python reference¶

    Everything the command line does is available from Python.

    from semantic_librarian import Document, Library

lib = Library.create("mylib")  # or Library.open("mylib")
lib.add_file("references.bib")
lib.add_documents([Document("note-1", {"text": "Some text."}, factors={"tag": ["idea"]})])
lib.build()

result = lib.search("attention and memory", mode="or", k=20)
for hit in result.hits:
    print(hit.rank, round(hit.score, 3), hit.document.title())

lib.similar("Crump, Matthew J. C.", space="author", target="document")
lib.project([hit.label for hit in result.hits], n_clusters=3)
lib.close()

    A library can also be used as a context manager: with Library.open("mylib") as lib:.

    Library¶

    semantic_librarian.library.Library ¶

    A library on disk. Open one with Library.open or make one with Library.create.

    is_built property ¶

    is_stale property ¶

    True when documents were added after the last build.

    create(root, name=None, **settings) classmethod ¶

    Create a new, empty library directory. settings are LibraryConfig fields.

    open(root) classmethod ¶

    add_file(path, fmt=None, mapping=None, split='document', force=False, chunk_words=DEFAULT_CHUNK_WORDS) ¶

    Ingest a file. Unchanged files that were added before are skipped.

    split applies to text files and chunk_words to PDFs.

    add_documents(docs, source=None, kind='python') ¶

    Add documents directly. Re-adding with the same source replaces them.

    build(embedder=None, params=None, log=None) ¶

    Embed every document and write all vector spaces.

    embedder and params override (and are saved into) the config.

    search(query, mode='compound', space='document', k=10, where=None, method='semantic', lexical_weight=0.5, include_stopwords=False) ¶

    Rank the items of space against a free-text query.

    Parameters:

    Name Type Description Default
    query str

    Free text; words not in the vocabulary are ignored (see unknown).

    		 required
    mode QueryMode

    How semantic scores combine query words: compound (sum of words), and or or; see semantic_librarian.search.similarity.

    		 'compound'
    space str

    Which space to rank: document, word, chunk (passages of PDFs) or any factor space.

    		 'document'
    k int | None

    Number of hits (None for all).

    		 10
    where Callable[[Document], bool] | None

    Optional document filter, e.g. lambda d: d.meta.get("year", 0) > 1990. In the chunk space it is applied to each chunk's document.

    		 None
    method str

    semantic (vector space), lexical (BM25 keywords) or hybrid (reciprocal rank fusion of the two). Lexical and hybrid rank documents.

    		 'semantic'
    lexical_weight float

    Share of the lexical ranking in a hybrid search (0 to 1).

    		 0.5
    include_stopwords bool

    Show stop words when ranking the word space.

    		 False

    similar(label, space='document', target=None, k=10, where=None, include_stopwords=False) ¶

    Items of target (default: the same space) closest to an existing item.

    Covers the original interface's article-article, author-author and article-to-author searches, and any other pairing of spaces.

    project(labels, space='document', n_clusters=3, seed=0) ¶

    2-D MDS map with k-means clusters for the given items of a space.

    document(doc_id) ¶

    chunk(label) ¶

    A chunk and the document it belongs to, by chunk label (<document id>#<n>).

    space(name) ¶

    Records¶

    semantic_librarian.document.Document dataclass ¶

    One searchable unit: an article, a book chapter, a sentence, a whole PDF...

    Attributes:

    Name Type Description
    id str

    Stable identifier, unique within a library.
    fields dict[str, str]

    Named text fields (title, abstract, body...). These are what gets embedded.
    meta dict[str, Any]

    Anything else worth displaying or filtering on (year, DOI, source path).
    factors dict[str, list[str]]

    Grouping variables, each with one or more levels. Every factor becomes its own vector space whose items are the sums of their documents' vectors; e.g. {"author": ["Crump, Matthew J. C.", "Logan, Gordon D."], "year": ["2010"]}.
    chunks list[Chunk]

    Passages of a long document, in reading order. A document with chunks is embedded from its chunks (its vector is the sum of theirs) and its fields are only displayed; each chunk is also searchable on its own in the chunk space.

    title() ¶

    semantic_librarian.document.Chunk dataclass ¶

    One passage of a long document, e.g. a few paragraphs of a PDF.

    Attributes:

    Name Type Description
    text str

    The passage.
    meta dict[str, Any]

    Where it came from, e.g. {"page": 3, "page_end": 4}.

    Vectors¶

    lib.space("author") returns a VectorSpace: labels names the rows of the numpy matrix vectors. Use it when you want the numbers themselves.

    semantic_librarian.space.vector_space.VectorSpace ¶

    Rows of vectors are items (words, documents, authors...) named by labels.

    All spaces produced by one build share coordinates, so any item can be compared with any other item, in the same or in a different space.

    Export¶

    semantic_librarian.export.bundle.export_library(lib, out, precision='int8', log=None, min_count=1) ¶

    Write the web app and the library's data to out.

    Parameters:

    Name Type Description Default
    lib Library

    A built library.

    		 required
    out Path | str

    Folder to write; it must be new, empty, or an earlier export (replaced).

    		 required
    precision Precision

    int8 (default, compact) or float32 (exact, four times larger).

    		 'int8'
    min_count int

    Leave out words that occur fewer than this many times in the library. The word vectors are usually the largest file a visitor downloads, and most words are rare. A word left out cannot be used in a query or shown as a result; documents and factors are unaffected.

    		 1
